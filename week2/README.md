# CS50 - Week 2 : Arrays

This folder contains my solutions to cs50 week 2 problems sets focusing on debugging, arrays and command-line arguments

## Completed Problem Sets
- **Readability** : Calculates the approximate grade level needed to read some text using calculations
- **Scrabble** : Game where letters in word gets converted to points and winner found
- **Substitution** : Enables you to encrypt messages using a substitution cipher by providing a command-line argument.

All programs were written in C as part of Harvard University's CS50 course.

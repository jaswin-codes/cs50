CS50 Problem Set 0 – Scratch
This is my submission for CS50 Problem Set 0.

## Project Description
A simple dodge game where the player must jump over or bend under 2 incoming lasers.
The game changes in speed randomly so try to successfully avoids the lasers.

## Controls
- Up arrow: Jump
- Down Arrow: Bend
-Left and Right Arrow: Move around

## Concepts Used
- Multiple sprites
- Variables (score, speed)
- Conditionals and loops
- Custom block with input for sprite movement

# CS50 - Week 4: Memory

This folder contains my solutions to the CS50 Week 4 problem sets, focusing on memory, pointers, malloc, file i/o and more.

## Completed Problem Sets
- **Volume** - Modifies the volume of an audio file either increasing or decreasing by factor
- **Recover** - Program that recovers photos that were "deleted"(forgotten) with file creation
- **Filter-more** - Using distribution code provided, write function to apply filters to Bit-map images of following: grayscale, reflection, blur and edge detection

All programs were written in C as part of Harvard University's CS50 course.

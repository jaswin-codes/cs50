# CS50 - Week 3: Algorithms

This folder contains my solutions to the CS50 Week 3 problem sets, focusing on algorithms. I learned about linear and binary search; selection, bubble and merge sort; creating own data type via struct and about recursion.

## Completed Problem Sets
- **Sort** : Using distribution code given of 3 sort files and numbers of varying quantity in 3 files (random, reversed, sorted), I was meant to find which was bubble, merge and selection sort 
- **Plurality** : Find winner of vote based on who has greatest number of votes
- **Tideman** : More difficult and complicated version where ranked-choice voting method is used to produce the winner

All programs were written in C as part of Harvard University's CS50 course.
